# Contributing

Thanks for helping improve VediSMM for Drupal.

- Use GitHub Issues for public bug reports and feature proposals.
- Use GitHub Security Advisories for vulnerabilities or credential exposure.
- Keep changes scoped to the Drupal plugin and its marketplace packaging.
- Run the platform tests and the shared CMS plugin contract checks before opening a pull request.
- Never commit `.env` files, reviewer credentials, API tokens, private keys, or screenshots that contain secrets.
