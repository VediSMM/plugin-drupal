# VediSMM для Drupal

VediSMM для Drupal подключает редакционный контент Drupal к API VediSMM по адресу `https://vedismm.ru/api/v1`.
Плагин будет приводить материал CMS к общему контракту `DraftInput`, создавать черновики VediSMM и давать редактору явные действия: сохранить как черновик, запланировать или опубликовать.

Статус: `0.1.0-dev`.

## Планируемые возможности

- Хранить API-токен VediSMM только в серверных настройках Drupal.
- Преобразовывать материал Drupal в поля `title`, `content`, `link`, `account_ids`, `group_ids` и `media_ids`.
- Создавать черновики со стабильным CMS-scoped idempotency key.
- Не публиковать автоматически при сохранении материала в CMS.
- Скрывать credentials и API-токены из логов, интерфейса, тестов и скриншотов.

## Локальная разработка

Этот репозиторий намеренно отделён от основного репозитория VediSMM.
До появления локальной копии фикстур используйте общий контракт CMS-плагинов из `docs/cms-plugin-contract.json` основного репозитория.
