# VediSMM для Drupal

VediSMM для Drupal подключает редакционный контент Drupal к API VediSMM по адресу `https://vedismm.ru/api/v1`.
Плагин будет приводить материал CMS к общему контракту `DraftInput`, создавать черновики VediSMM и давать редактору явные действия: сохранить как черновик, запланировать или опубликовать.

Статус: `1.1.0`.

## Планируемые возможности

- Хранить API-токен VediSMM только в серверных настройках Drupal.
- Преобразовывать материал Drupal в поля `title`, `content`, `link`, `account_ids`, `group_ids` и `media_ids`.
- Создавать черновики со стабильным CMS-scoped idempotency key.
- Не публиковать автоматически при сохранении материала в CMS.
- Давать нативные зависимые опции сокращения ссылок и источника площадки для каждой отправки; по умолчанию обе выключены.
- Скрывать credentials и API-токены из логов, интерфейса, тестов и скриншотов.

Настройки передаются только как `options.tracking.shorten_links` и
`options.tracking.add_source`. Источник доступен только вместе с сокращением:
выключение сокращения принудительно выключает источник. Модуль отправляет
исходный контент и URL без изменений и не хранит состояние созданных ссылок.
Form token/CSRF предоставляет Drupal Form API; отдельное поле токена не
добавляется.

При включённом источнике ВедиSMM использует ключ каждой целевой площадки. Если
непустой `utm_source` отсутствует, добавляется `utm_source=<network>`, а
существующий `utm_term` сохраняется. Если `utm_source` уже есть, он сохраняется,
а все значения `utm_term` заменяются (или добавляется одно) ровно одним
`utm_term=<network>`. Остальные query-параметры, encoded values, их порядок и
fragment сохраняются.

## Локальная разработка

Этот репозиторий намеренно отделён от основного репозитория VediSMM.
До появления локальной копии фикстур используйте общий контракт CMS-плагинов из `docs/cms-plugin-contract.json` основного репозитория.
